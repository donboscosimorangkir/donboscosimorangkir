## 🎓 Final Year Project

**Analysis of Performance and Resource Efficiency of ML-KEM and HQC for Key Establishment and ML-DSA and SLH-DSA for Digital Signature on ESP32-WROOM-32**

My research focuses on evaluating post-quantum cryptographic algorithms for IoT devices with limited hardware resources.

| Component | Description |
|:--|:--|
| Key Establishment | ML-KEM and HQC |
| Digital Signature | ML-DSA and SLH-DSA |
| Hardware | ESP32-WROOM-32 |
| Communication | Wi-Fi / TCP-IP |
| Evaluation | Execution time, memory, storage, and energy consumption |

The objective is to analyze the trade-offs between cryptographic security, computational performance, and resource efficiency on embedded hardware.
