<h2 align="center">Final Project</h2>

**Performance and Resource-Efficiency Analysis of ML-KEM and HQC for Key Establishment on ESP32-WROOM-32**

- **Goal:** compare two post-quantum key encapsulation mechanisms on a resource-constrained microcontroller
- **Platform:** ESP32-WROOM-32 with ESP-IDF
- **Metrics:** execution time, memory usage, and resource efficiency
- **Why it matters:** IoT devices need key establishment that stays secure against future quantum attacks without exceeding hardware limits
